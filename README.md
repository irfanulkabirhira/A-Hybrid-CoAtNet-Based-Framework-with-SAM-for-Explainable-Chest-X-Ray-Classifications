# A-Hybrid-CoAtNet-Based-Framework-with-SAM-for-Explainable-Chest-X-Ray-Classifications
Hybrid CoAtNet-0 + Sharpness-Aware Minimization (SAM) framework for explainable chest X-ray classification. Integrates Grad-CAM, SHAP, and LIME for multi-level interpretability. Achieves 93% accuracy on Epic Chittagong dataset for pneumonia detection.
